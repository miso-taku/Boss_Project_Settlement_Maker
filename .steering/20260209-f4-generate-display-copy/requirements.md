# F4: 生成実行・返信案表示（1件）・コピー — 要求

## 背景 / 目的

- **背景**: F3 で入力フォームが実装され、ユーザーが依頼文と自分の状況を入力できるようになった。次に、フォームの入力値を基に API を呼び出して返信案を生成し、生成された返信案を表示・コピーできる機能を実装する必要がある。
- **目的**: `ReplyForm` コンポーネントに生成実行ボタンを追加し、API を呼び出して返信案を取得する。取得した返信案（1件）を表示し、ユーザーがコピーできる機能を実装する。functional-design.md 2.1 に従い、出力エリアを構成する。

## スコープ（やること / やらないこと）

### やること

- 生成実行ボタンの実装
  - フォームの入力値を取得
  - API クライアント関数（`generateReplyDrafts`）を呼び出し
  - エラーハンドリング（F5 で詳細な UI 表示を実装するが、今回は基本的なエラー処理）
- 返信案表示コンポーネントの実装
  - 返信案1件をカードまたはブロックで表示
  - 返信案のテキストを読みやすく表示
- コピー機能の実装
  - 「コピー」ボタンで返信案のテキストをクリップボードにコピー
  - コピー成功時のフィードバック（例：トースト、ボタン表示変更）
- 状態管理の拡張
  - ローディング状態（F5 で詳細な UI 表示を実装するが、今回は基本的な状態管理）
  - エラー状態（F5 で詳細な UI 表示を実装するが、今回は基本的な状態管理）
  - 返信案データの保持
- `./docs/implementation-tasklist.md` の F4 を完了に更新

### やらないこと

- エラーハンドリングの詳細な UI 表示（F5 で実施）
- ローディング表示の詳細な UI（F5 で実施）
- 返信案の編集機能（Out of Scope）
- 返信案の履歴保存（Out of Scope）
- 複数返信案の表示（仕様上1案のみ）

## 受け入れ条件（Given-When-Then）

- **Given** 入力フォームが実装済み（F3 完了）
- **Given** API クライアントが実装済み（F2 完了）
- **When** 依頼文と自分の状況を入力して生成実行ボタンをクリックする
- **Then** API が呼び出され、返信案が取得される
- **And** 返信案1件が表示される

- **And** 「コピー」ボタンで返信案のテキストをクリップボードにコピーできる
- **And** コピー成功時にフィードバックが表示される
- **And** `./docs/implementation-tasklist.md` の F4 が完了に更新されている

## 未決事項 / リスク / 仮定

- **仮定**: ローディング表示は F5 で詳細な UI を実装するが、今回は基本的な状態管理（例：ボタンの disabled 状態）のみを実装する。
- **仮定**: エラーハンドリングは F5 で詳細な UI 表示を実装するが、今回は基本的なエラー処理（例：`console.error`、エラー状態の保持）のみを実装する。
- **仮定**: コピー機能は `navigator.clipboard.writeText()` を使用する。ブラウザの互換性は考慮するが、モダンブラウザを前提とする。
- **仮定**: コピー成功時のフィードバックは、ボタンの表示変更（例：「コピー済み」）または簡易的なトースト表示とする。詳細なトーストライブラリの導入は F5 以降で検討する。
- **仮定**: 返信案の表示は、テキストをそのまま表示する（改行は保持）。スタイリングは必要最小限とする。
- **リスク**: API 呼び出し中の重複実行を防ぐ必要がある。ボタンの disabled 状態で制御する。
- **リスク**: コピー機能がブラウザでサポートされていない場合のフォールバックが必要になる可能性がある。今回は基本的な実装のみとする。
