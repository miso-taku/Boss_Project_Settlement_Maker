# ユビキタス言語定義（Glossary）

本プロダクト「上司案件・落とし所AIエージェント」で用いる用語・概念の定義。仕様・設計・コードで一貫して使用する。

---

## プロダクト・ドメイン

| 用語 | 定義 |
|------|------|
| **上司案件・落とし所AIエージェント** | 相手（上司など）の依頼に対して、角の立たない断り・代替案・確認質問・次の一手を生成するAIアプリ。サブタイトル：「今日中に」を今日中にしないAI。 |
| **依頼文** | 相手（上司など）から受け取った依頼のテキスト。入力の一つ。 |
| **自分の状況** | ユーザー側の制約・リソースを表す入力。残り時間・優先度・制約（自由文）で構成する。手動入力または Google Calendar から取得して導出する。 |
| **自分の状況の入力元** | 手動入力（残り時間・優先度・制約を直接入力）か、Google Calendar から取得（対象日の予定から残り時間・制約を導出）かを選択する。 |
| **予定取得** | Google Calendar の予定を MCP（mcp-google）経由で取得し、残り時間・制約を導出すること。 |
| **残り時間** | 今日（または対象期間）で使える作業時間。数値（単位は時間または分）で入力する。 |
| **優先度** | 既存タスクや依頼の重要度。3段階で選択する（例：高／中／低）。 |
| **制約** | ユーザーが守りたい条件・NG事項・落とし所などを自由文で記述したもの。 |
| **落とし所** | 交渉の結果として許容できる妥協点。例：「最小なら今日、完成は明日」。 |
| **返信案** | AIが生成した、相手に返す返信の文案。1案を表示する。 |
| **角の立たない断り** | 依頼をそのまま受けられない場合の、丁寧な拒否・条件付き受諾の表現。 |
| **代替案** | スコープ縮小・期限延長・分割・他者紹介・優先順位調整などの選択肢。 |
| **確認質問** | 相手に投げて、交渉を前に進めるための質問。 |
| **次の一手** | 2ターン目の返信として使える、交渉を進める一文・提案。 |
| **返信案生成エージェント** | 依頼文＋自分の状況を入力とし、返信案リスト（初稿）を生成する AI エージェント。 |
| **返信案チェックエージェント** | 返信案リスト＋依頼文・自分の状況を入力とし、3項目（角の立たなさ・代替案・確認質問の適切さ・依頼文・制約準拠）をそれぞれ10点満点で評価する AI エージェント。全て8以上で合格、1つでも8未満なら NG とし must_fix（必須修正）・nice_to_have（任意改善）を箇条書きで返す。 |
| **返信案作り直しエージェント** | 返信案リスト＋チェック指摘（must_fix / nice_to_have）＋依頼文・自分の状況を入力とし、指摘を踏まえて修正した返信案リストを返す AI エージェント。 |
| **チェック結果** | 返信案チェックエージェントの出力。3項目のスコア（各0〜10）と must_fix（必須修正・箇条書き）・nice_to_have（任意改善・箇条書き）。合格は全スコア8以上。 |

## 技術・レイヤ

| 用語 | 定義 |
|------|------|
| **FE** | フロントエンド。本プロダクトでは React/Next.js。 |
| **BE** | バックエンド。本プロダクトでは Python (FastAPI)。 |
| **Domain** | ドメイン層。エンティティ・値オブジェクト・集約・ドメインサービス。副作用・I/O禁止。 |
| **Application** | アプリケーション層。ユースケース（コマンド/クエリ）。Domain を組み合わせ、Port 越しにインフラを利用。 |
| **Infrastructure** | インフラ層。DB・外部API等の具体実装（Adapter）。 |
| **Interface (Presentation)** | プレゼンテーション層。FastAPI ルータ・DTO・認証・入力検証。 |
| **Port** | ドメイン/アプリケーションが依存する抽象（例：AI呼び出しの抽象）。 |
| **Adapter** | Port の具体実装（例：PydanticAI を呼ぶ実装）。 |
| **Usecase** | アプリケーション層のユースケース。一つの「やりたいこと」を実現する。 |
| **DTO** | Data Transfer Object。API の入出力を表すデータ構造。 |
| **契約** | API のリクエスト/レスポンスの型・仕様。OpenAPI で定義し、FE/BE で共有する。 |
