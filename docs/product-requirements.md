# プロダクト要求定義書（Product Requirements）

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| プロダクト名 | 上司案件・落とし所AIエージェント |
| サブタイトル | 「今日中に」を今日中にしないAI |
| 概要 | 相手（上司など）の依頼文と自分の状況を入力すると、角の立たない断り・代替案・確認質問・次の一手（返信案）を生成するデモアプリ。 |

---

## 2. 背景・目的

### 背景

- 急な依頼（「今日中に」等）に対して、そのまま受けると品質や負荷に無理が生じることがある。
- 断り方・代替案の出し方・確認質問の立て方が難しく、返信に困ることがある。

### 目的

- 依頼文と自分の状況を入力するだけで、**角の立たない断り**・**代替案**・**相手に投げる確認質問**・**交渉を前に進める次の一手（2ターン目の返信案）**までをAIが生成する。
- ユーザーは返信案をコピー等で実際の返信に利用できる。

---

## 3. スコープ

### やること（In Scope）

- **入力**
  - 相手の依頼文（自由文）
  - 自分の状況：
    - 残り時間（数値入力）
    - 優先度（3段階選択）
    - 制約（自由文）
- **出力**
  - 1件の返信案を表示（角の立たない断り・代替案・確認質問・次の一手を含む）
  - ユーザーが返信案をコピー等する
- **技術**
  - フロントエンド: React/Next.js
  - バックエンド: Python (FastAPI + PydanticAI)
  - AI: OpenAI モデル（gpt-5-mini または API 仕様に合わせた同等モデル）
- **利用形態**
  - デモアプリとして認証なしで提供

### やらないこと（Out of Scope）

- ユーザー認証・ログイン
- 返信の送信機能（メール/Slack 等への直接送信）
- 返信案のアプリ内編集UI（選んでコピーする運用で足りる）
- 履歴の永続保存（必要になったら別タスクで検討）

---

## 4. 受け入れ条件（Acceptance Criteria）

### 4.1 入力〜生成

- **Given** 依頼文と自分の状況（残り時間・優先度・制約）を入力した  
- **When** 生成を実行する  
- **Then** 1件の返信案が表示される  
- **And** 返信案には、角の立たない断り・代替案・確認質問・次の一手に相当する内容が含まれる  

### 4.2 出力の利用

- **Given** 返信案が表示されている  
- **When** ユーザーが返信案をコピー等する  
- **Then** その文案を外部（メール・チャット等）で利用できる  

### 4.3 入力形式

- **Given** 自分の状況を入力する  
- **When** 残り時間・優先度・制約を入力する  
- **Then** 残り時間は数値で、優先度は3段階で選択し、制約は自由文で入力できる  

---

## 5. 影響範囲

| 領域 | 内容 |
|------|------|
| FE | Next.js（React）UI（入力フォーム・生成実行・返信案一覧表示・コピー） |
| BE | FastAPI + PydanticAI（エージェント・プロンプト・API） |
| API | 依頼文＋自分の状況を送り、返信案リストを返す契約 |
| DB | 初版では不要（認証・履歴なし） |
| Docs | 本要求・機能設計・技術仕様・用語・タスクリストを ./docs で管理 |

---

## 6. 制約・仮定

- **認証**: なし。デモ用途を前提とする。
- **AIモデル**: gpt-5-mini（実装時に API で利用可能なモデル名に合わせる。gpt-4o-mini 等の可能性あり）。
- **永続化**: 初版では依頼・返信の履歴保存は行わない。
