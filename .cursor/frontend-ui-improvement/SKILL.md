# Frontend UI Improvement

## Steps
1. 期待をテストで固定（コンポーネント/UX）。:contentReference[oaicite:26]{index=26}
2. UI実装：状態管理/API呼び出しは既存パターンに寄せる。:contentReference[oaicite:27]{index=27}
3. 業務ルールは過剰にFEに寄せない（BEと二重化しない）。:contentReference[oaicite:28]{index=28}
4. 仕様に影響するなら `./docs` を同一PRで更新。:contentReference[oaicite:29]{index=29}
5. `./docs/implementation-tasklist.md` を更新。:contentReference[oaicite:30]{index=30}
6. `.steering` をモード3で振り返り更新。:contentReference[oaicite:31]{index=31}

## Output checklist
- [ ] 画面/UX変更の根拠（なぜ）を説明できる
- [ ] 追加/更新したテストが明記されている
- [ ] docs / steering / implementation-tasklist が更新済み :contentReference[oaicite:32]{index=32}
